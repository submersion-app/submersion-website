Submersion + Adobe Lightroom

Submersion is a scuba dive-logging app. This integration links a diver's Adobe Lightroom cloud photos and videos to their dive logs automatically, matched by the moment each shot was captured.

What it does

After a diver connects their Adobe account, Submersion reads their Adobe Lightroom cloud catalog, matches photos and videos to dives by capture time, and shows each shot on the corresponding dive - with a one-tap "Open in Lightroom" link back to the original. The integration is read-only: Submersion never modifies the diver's Lightroom catalog.

How a user connects (end to end)

  1. In Submersion, open Settings → Photos & Media → Photo library & sources → Adobe Lightroom and choose Connect with Adobe.
  2. The system browser opens Adobe's sign-in page. The user signs in with their own Adobe ID and approves the requested access.
  3. The browser returns to Submersion and the account is connected. There is no developer setup and no keys to paste - the user only signs in.
  4. Submersion scans the diver's trips and attaches confident photo matches automatically; ambiguous ones appear as one-tap suggestions on the dive.
  5. Each linked photo or video then appears on its dive, with Open in Lightroom to view the original in Adobe Lightroom.

What it accesses, and why

Scope Why Submersion requests it
openid, AdobeID Identify the signed-in Adobe user (their account name / email is shown in Settings).
lr_partner_apis Read the user's Lightroom catalog - account, catalog id, albums, and asset metadata (capture time, filename) - to match shots to dives.
lr_partner_rendition_apis Fetch a display rendition of each matched photo or video so it can be shown on the dive.
offline_access Requested so the connection can persist across sessions; used only if Adobe issues a refresh token for the credential.

Technical summary (for the review team)

Integration type Adobe Lightroom Services API (Creative Cloud), via Adobe IMS OAuth 2.0. This integration does not use the Adobe Express Embed SDK.
Credential OAuth Native App (public client, PKCE, no client secret). Client ID 00f3c953c816414db32d7ee98873040d.
Authorization Three-legged and user-consented. Authorize endpoint ims-na1.adobelogin.com/ims/authorize/v2; token endpoint ims-na1.adobelogin.com/ims/token/v3.
API base lr.adobe.io - /v2/account, /v2/catalog, /v2/catalogs/{id}/albums, /v2/catalogs/{id}/assets, /v2/catalogs/{id}/assets/{id}/renditions/{size}.
Platform Native app (Flutter) for macOS, Windows, Linux, iOS, and Android. Because it is a native app rather than a hosted web app, the workflow is documented here and shown in the demo video.
Data handling Read-only. Renditions are cached on the user's own device or the user's own cloud storage. Submersion operates no server that stores Adobe tokens or user photos.
